元画像を参照して、同じキャラクターの話しているアニメーション用スプライトシートを作成してください。
4列×4行、合計16コマのスプライトシートにしてください。
横方向は目の変化、縦方向は口の変化です。
各コマは同じサイズで、キャラクターの顔の位置・角度・構図・髪型・服装・輪郭を完全に固定してください。
変化させるのは基本的に目と口だけです。
背景は透過、または単色で分離しやすくしてください。
文字や番号は入れないでください。
スプライトシート全体を1枚の画像として出力してください。

列（左から右）の目の状態：

1. 目をしっかり開いた状態
2. 目を1/3ほど閉じた状態
3. 半目
4. 完全に目を閉じた状態

行（上から下）の口の状態：

1. 口を閉じた状態
2. 少し口を開けた状態
3. 中くらいに口を開けた状態
4. 大きく口を開けた状態

各16コマは、上記の目と口の組み合わせをすべて埋めてください。
口パクと瞬きのアニメーションに使いやすいよう、各コマ間の差分は自然で、整列が正確で、顔の位置ずれがないようにしてください。
まばたきはまぶたの開閉で表現し、目の横幅や顔全体の形が不自然に変化しないようにしてください。
口の開きは会話アニメ向けに自然に段階化し、歯や舌の描写は必要最小限で、元画像の絵柄に合わせてください。
元画像のキャラクターデザイン、色、塗り、線のタッチ、雰囲気を忠実に維持してください。

背景の色は黒にしてください。
