# 顔画像グループの使用仕様

[English](face_image_usage_analysis.md) | [日本語](face_image_usage_analysis.ja.md)

この文書は、顔画像v2の各グループが実行時にどう使われるかをまとめます。移行前の129枚構成と旧静止顔の分析は`v0.3.1`タグを参照してください。

## 表示の優先順位

```text
travel still > shake/dizzy recovery > guruguru > petting animation > base animation
```

好感度、認証、熱、低電力、撮影状態は顔画像グループを切り替えません。必要な状態はoverlayや処理として維持します。

## 基本アニメーション

`base_m0_e0..base_m3_e3`は、行が口4段階、列が目4段階です。

- 待機・聞き取り: 通常は`m0`
- 発話: 音量に応じて`m0..m3`
- まばたき: `e0 → e1 → e2 → e3 → e3 → e2 → e1 → e0`
- shake復帰: 口閉じのまま`e3 → e2 → e1 → e0`

マイク接続中でも、口閉じ表示に16枚全体のキャッシュを要求しません。キャッシュ確保に失敗した場合は、要求されたv2画像をLittleFSから直接描画します。

## なでなで

`pet_anim_0..15`は4×4シートを行優先で分割した16コマです。

- 開始: `0 → 1 → 2`
- 撫でられ中: `3 → 4 → 5 → 6 → 7 → 5 → 4 → 6`
- 終了遷移: `2 → 1 → 0`
- 3秒以上で終了: `8 → 9 → 10 → 11 → 9 → 8 → 0`の喜び
- 3秒未満で終了: `12 → 13 → 14 → 15 → 12 → 0`の不満

入力はCoreS3が背面タッチ、StopWatchが画面中央付近のタッチ／ドラッグ、AtomS3Rが通常画面でのBtnA長押しです。

## ぐるぐると混乱

- CoreS3/AtomS3R: `dir0..16`、中央`blink16`
- StopWatch: `dir0..8`、中央`blink8`
- 混乱: `dizzy_01..15`

方向顔は傾きやタッチ方向へ追従し、混乱判定後は`dizzy_*`を再生します。混乱終了後は基本アニメーションの閉じ目から通常目へ戻ります。

## 旅モード

旅モードは`travel_*`9表情と、既存の`pet_anim_*`／`dizzy_*`6表情を写真向け静止顔として使用します。選択中はアプリから一時的なstate変更を受けても同じ画像を維持し、別表情の選択、通常顔へのリセット、または旅モード終了まで口パクとまばたきを行いません。

ピッカーページは表示専用の合成JPGであり、顔アニメーションframeではありません。CoreS3は320×240、StopWatchは386×386です。

## タイムキーパー

タイムキーパーUIは顔の上へframe overlayとして合成します。チャレンジ結果の誤差が200ms以内の場合は`pet_anim_0,8,9,10,9,8,0`を専用笑顔として再利用し、終了後に通常のキャッシュ状態へ戻します。

## 旧互換

`transition`はmanifestなしの`voice_m*_e*` 16枚、`legacy`は旧基本5枚だけを対象とします。現行v2配布には`idle`、`talk_*`、`good_*`、`bad_*`、`photo_*`、tier、thermal、low-power画像を含めません。
